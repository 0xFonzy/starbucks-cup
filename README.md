# Holiday Cup Puzzle

A 3×3 picture puzzle. Eight squares show pieces of a holiday coffee cup scene and one square is white.

## How to play

1. Tap a picture tile to pick it up.
2. Tap the white square to move the tile there.
3. Put all nine squares back in order to finish the picture.

By default only tiles touching the white square can move (the classic sliding-puzzle rule). Switch
"Which tiles can move?" to **Any tile** for an easier game. Every shuffle is solvable in both modes.

## Run it

Open `index.html` in a browser. It is a single self-contained file with no build step.
